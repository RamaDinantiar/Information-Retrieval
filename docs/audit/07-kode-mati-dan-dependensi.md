## 7. Cara pemeriksaan dan batasannya

- **Berkas frontend mati:** skrip Python membangun grafik impor dari seluruh `resources/js` (alias `@/` dan relatif), lalu menelusuri keterjangkauan dari halaman dan titik masuk. Berkas hasil generate (`routes`, `actions`, `wayfinder`) dikecualikan. Satu percobaan awal dengan skrip shell salah dan hasilnya dibuang.
- **Dependensi npm:** dicocokkan dengan impor di berkas yang terjangkau, lalu diperiksa manual untuk peer dependency dan pemakaian lewat CSS.
- **PHP:** kelas dan metode publik yang namanya hanya muncul sekali di `app`, `routes`, `config`, `database`, `tests`, `resources/views`; route dibandingkan dengan `route:list`. Hasil dicek untuk pemakaian otomatis (perintah, listener, Fortify).
- **Tidak diperiksa:** CSS tak terpakai, aset gambar atau font tak terpakai, metode privat/terproteksi, dan pemakaian dinamis berbasis string (mis. `route($variabel)`).
